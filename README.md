# Gradient Boosting Regressor Guide

This project explains how Gradient Boosting works for predicting continuous values and tests it with Python code.

## Main Concepts
- Calculating initial predictions (average).
- Finding errors (residuals) and training new trees to fix those errors.
- Combining all trees using a learning rate to get the final prediction.
- Trained a GradientBoostingRegressor on the Boston Housing dataset.

## Tools Used
- Python
- Scikit-Learn
- Pandas
